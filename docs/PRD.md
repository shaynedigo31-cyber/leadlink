# Product Requirements (summary)

**Product:** LEADLINK — centralized, multi-organization platform for student organizations. **Identity:** LEADSPIRE. **Budget:** zero (free tools and free tiers only).

## Goals
Run organization operations and preserve knowledge between administrations.

## Modules
Auth and personal dashboard · Organization management · Events · Projects and tasks · Announcements and notifications · Library (folders, per-folder permissions, versions, recovery) · Legacy · LEADSPIRE · Leadership turnover · Platform administration.

## Roles
Platform administrator, organization owner, organization administrator, officer, member, adviser. One account, many organizations, different role per organization. Position titles are separate from permissions.

## Status
Only the Phase 1 interface shell exists. Everything else is planned. See DEVELOPMENT_ROADMAP.md.
