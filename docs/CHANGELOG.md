# Changelog

## 0.2.0 — Phase 2 foundation (unreleased, untested)
- Supabase client and AuthContext (session, profile name, memberships).
- Real login and registration via Supabase Auth; protected routes.
- Database migration for profiles, organizations, roles and memberships with RLS.
- Dashboard shows real memberships and can register an organization (pending approval).
- Organization dashboard shows the real name and role; stats and lists are still sample data.
- Workflow passes Supabase variables to the build.

## 0.1.0 — Phase 1 foundation
- Vite, React, TypeScript, Tailwind, Lucide, HashRouter. Public pages, app shell, dashboards, docs, deploy workflow.
